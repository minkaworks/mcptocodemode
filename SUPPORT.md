# Support

| You want | Where |
| --- | --- |
| Help running the server | [Question](https://github.com/minkaworks/mcptocodemode/issues/new?template=question.yml) |
| A defect | [Bug report](https://github.com/minkaworks/mcptocodemode/issues/new?template=bug_report.yml) |
| A change to the product | [Feature request](https://github.com/minkaworks/mcptocodemode/issues/new?template=feature_request.yml) |
| The protocol contract | [SPEC.md](SPEC.md) |
| The measurements | [REPORT.md](REPORT.md) |
| A vulnerability | [SECURITY.md](SECURITY.md) |

There is no private support contract. A security report does not go to the public issue tracker.
